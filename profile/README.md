# FastCopy Pro

## Four Beats

1. **Name the tree.** Give the FastCopy Pro session a short title before you point a source folder at a destination path.
2. **Pin the live jobs.** Keep current file copy jobs and the destination path on the FastCopy Pro board and leave unused trees aside.
3. **Check the verify pass.** Read the FastCopy Pro summary of the verify pass before you treat a large folder move as final.
4. **Close the loop.** Note which jobs are ready so the next FastCopy Pro visit does not start by hunting the destination path.

## Field Note

FastCopy Pro is easier to trust when the job stays smaller than the tree it came from. A named session shows which source is active, the pins show which file copy jobs you will run today, and the closing note tells the next person which destination path drives the large folder move. That record is short on purpose: not a copy of every file, only the path back to the verify pass that is still open on the reader's own folders.

The same loop fits a student lab tree, a client packet you own, or a computer shared by two team members. Open the last FastCopy Pro session, confirm one destination path, and leave the file copy jobs easier to follow than you found them. Other programs stay where they are. FastCopy Pro only holds the destination path, the verify pass, and the handoff.

## One Real Pass

Pick a folder that already has a name and that you own: a short project tree, a lab packet on your desk, or a thin working directory. Open it in FastCopy Pro, keep only that job on the board, and read one destination path you can point to. A pass is done when that path stays tied to the file copy jobs and the unused trees are no longer in the way. FastCopy Pro does not need a full rebuild of the working set before it is useful.

If the pass feels crowded, the tree is too wide. Drop anything that belongs to a different job and leave it out of this workspace. The next pass can have its own title. What matters is that this one stays readable from the first source to the last destination, with the summary still matching the verify pass on that PC.
